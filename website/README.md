# موقع عيادة الدكتورة فايزة — V3

موقع عربي متعدد الصفحات، ثابت وسريع، باستخدام HTML مولَّد أثناء البناء دون إطار عمل ثقيل.

## التشغيل
من داخل `website`:

```bash
npm run build
python -m http.server 8000 -d dist
```

## البنية
- `build.mjs`: مصدر موحد لبيانات الصفحات والخدمات، وينتج HTML ثابت لكل رابط.
- `src/styles.css`: نظام التصميم والتجاوب Mobile-first.
- `src/client.js`: سلوك قائمة الهاتف.
- `assets/illustrations/`: رسوم توضيحية طبية أصلية بصيغة SVG.
- `assets/`: الشعارات الأصلية والصور التوضيحية القديمة المعتمدة.

## الصفحات
الرئيسية، عن الدكتورة، الخدمات وست صفحات خدمة تفصيلية، المختبر والتشخيص، التوعية وثلاثة مقالات، الأسئلة الشائعة، والتواصل. تُولّد ملفات sitemap.xml وrobots.txt و404.html تلقائيًا.

## المرجع التحريري
تُراجع البيانات دائمًا مقابل `../docs/CLINIC_MASTER.md` والهوية `../brand/guidelines/VISUAL_IDENTITY.md`. لا ننشر صور الغرفة أو الطفل على أنها صور مثبتة لمقر العيادة. لا ننشئ محتوى طبيًا مضللًا أو قائمة أجهزة غير معتمدة. معلومات العروض محدودة الصلاحية ولم تُدرج ضمن الصفحات الدائمة.
