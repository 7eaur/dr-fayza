# موقع عيادة الدكتورة فايزة — النسخة الموحدة

موقع عربي RTL ثابت متعدد الصفحات ومهيأ للهاتف، مبني بـ Node.js دون إطار عمل أو نظام حجوزات غير مطلوب.

## مصدر النسخة
`main` هو الفرع المنشور؛ تُراجع التحديثات في فرع مستقل قبل دمجها.
النسخة السابقة لـ `main` محفوظة في `backup/main-before-unified-release-20261112`.

## التشغيل
```bash
cd website
npm ci
npm run build
python3 -m http.server 8000 -d dist
```

## هيكل الموقع
- `build.mjs`: مصدر الصفحات، الخدمات والمقالات وبيانات SEO وبناء ملفات HTML.
- `src/styles.css`: الأساس السابق لنظام العناصر.
- `src/agency.css`: هوية النسخة الموحّدة والتجاوب وتحسينات الوصولية.
- `src/client.js`: قائمة الهاتف، تحريك صورة الشعار الأصلية داخل الهيدر، ظهور الأقسام وحالات تحميل الصور.
- `scripts/visual-audit.mjs`: لقطات واختبارات المتصفح والوصولية عبر Playwright/Axe.
- `scripts/performance-audit.mjs`: فحص المقاسات وبصمات الأصول والصور المتجاوبة والتصفح عند تقليل الحركة أو تعطّل JavaScript والصور.
- `check.mjs`: فحص صفحات وروابط ومحتوى مخرجات البناء.

## المحتوى
19 صفحة: الرئيسية، عن الدكتورة، الخدمات و6 صفحات تفاصيل (يتضمن دليل الخدمات المختبر والفحوصات)، فهرس التوعية الصحية و7 مقالات، الأسئلة الشائعة، والتواصل.
ملفات `sitemap.xml`, `robots.txt`, `404.html` تُنشأ مع كل بناء.

## قواعد المحتوى
المصدر الرسمي `../docs/CLINIC_MASTER.md` والهوية `../brand/guidelines/VISUAL_IDENTITY.md`.
صور الموقع العامة توضيحية وليست صوراً حقيقية للعيادة. لا تضاف خريطة رسمية أو بيانات اعتماد أو تقييمات دون توثيق.
رابط الخرائط الحالي **بحث بالعنوان المعلن فقط**، وليس دبوساً موثقاً.
حالات الولادة فقط مُعلن استقبالها على مدار 24 ساعة؛ باقي الخدمات وفق الدوام أو التواصل.

## التحميل والحركة
المحتوى ثابت وقابل للقراءة دون JavaScript. صور الهيرو فورية؛ صور ما تحت الشاشة تستخدم التحميل المؤجل الأصلي للمتصفح، مع أبعاد محجوزة وإعادة محاولة عند فشل الصورة. مصادر الصور وpreload مشتقة من نفس المقاسات. الملفات والخطوط محلية وتصدر تحت `/static/<content-hash>/` بكاش سنة، بينما تبقى الروابط الثابتة قابلة لإعادة التحقق. يتحقق البناء من قواعد CSS المستخدمة ويحذف غير المستخدمة. تحترم حركات الأقسام والتنقل تفضيل تقليل الحركة؛ لا توجد مهلة اصطناعية للنقر على الروابط. تتحرك صورة الشعار الموجودة في الهيدر مرة واحدة، دون إنشاء صور إضافية أو شاشة تحميل. زر العودة للأعلى يظهر بعد التمرير، ويعمل برابط حقيقي مع دعم لوحة المفاتيح وتقليل الحركة.
