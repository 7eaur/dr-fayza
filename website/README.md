# موقع عيادة الدكتورة فايزة — One Page

موقع عربي بصفحة واحدة، بتصميم مستوحى من الصورة المرجعية المعتمدة، مبني بـ HTML/CSS/JavaScript دون إطار ثقيل.

## التشغيل

افتح `index.html` بالمتصفح أو شغّل خادمًا محليًا في المجلد:

```sh
python -m http.server 8000
```

ثم افتح `http://localhost:8000`.

## الملفات

- `index.html`: أقسام الصفحة والبيانات وروابط التواصل.
- `styles/site.css`: التصميم المتجاوب والهوية.
- `scripts/site.js`: قائمة الهاتف والتنقل وبعض التفاعلات.
- `assets/clinic-hero.webp`: صورة غرفة الفحص التي قدمها صاحب المشروع، ومستخدمة كصورة توضيحية، لا كتصوير موثق للعيادة.
- `assets/newborn-banner.webp`: صورة الطفل التي قدمها صاحب المشروع، ومستخدمة في شريط استقبال الولادة.

## الشعار

تُستخدم روابط الصور الأصلية من مستودع [dr-fayza](https://github.com/7eaur/dr-fayza) مباشرةً: `brand/logos/secondary` و`brand/symbols`. يلزم الإنترنت لعرض الشعار في حزمة المعاينة المنفصلة، أو نسخ الأصول محليًا مع تعديل المسارات. لا تجوز إعادة رسم الشعار أو تشويهه.

## ملحوظات قبل النشر

- صور الغرفة والطفل توضيحية، وليست صورًا موثقة من مقر العيادة. استبدلها إذا توفرت صور حقيقية معتمدة.
- يجب التأكد من جهة استقبال الولادة خلال 24 ساعة ووسيلة الاتصال العاجلة وموقع تقديم الخدمة.
- راجع أسماء المؤهلات والتفاصيل الطبية وصحة الروابط عند الاعتماد النهائي.
- لا يستخدم الموقع قاعدة بيانات أو يجمع بيانات المرضى.
- رابط الدومين وخرائط Google ووسائل التواصل غير المؤكدة لم تُفترض.
- يفضل إضافة الخط محليًا بترخيص صحيح بدل استيراده من Google Fonts قبل النشر النهائي.

## المرحلة الحالية

نسخة واجهة قابلة للتشغيل والتعديل؛ غير منشورة على استضافة إنتاجية، ولم تخضع بعد لاختبار مرور شامل في المتصفحات والأجهزة الحقيقية.
