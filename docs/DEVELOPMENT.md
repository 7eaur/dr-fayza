# تطوير موقع عيادة الدكتورة فايزة

## البنية

موقع ثابت من 19 صفحة عربية، يُبنى باستخدام Node.js وينشر من `main` على Vercel، ومجلد المشروع لدى الاستضافة هو `website`.

- `website/src/content.mjs`: البيانات المشتركة والخدمات والأسئلة والمقالات.
- `website/build.mjs`: قوالب الصفحات والبيانات المنظمة وبناء HTML وتحسين الأصول.
- `website/src/styles.css`: مصدر التنسيق الوحيد، ويشمل الخطوط والتجاوب والحركة.
- `website/src/client.js`: القائمة وحركة الشعار والصور والعودة للأعلى.
- `website/assets/`: الصور المستخدمة والخطوط المحلية وترخيصها.
- `tools/build_social_card.mjs`: يولّد صورة المشاركة 1200×630 من الشعار وصورة العيادة والخط المحلي أثناء البناء.

بيانات العيادة ومؤهلات الطبيبة في [CLINIC_MASTER.md](CLINIC_MASTER.md)، والهوية الأصلية في [دليل الهوية](../brand/guidelines/VISUAL_IDENTITY.md). مواد الحملات في `campaigns/` مستقلة عن محتوى الموقع ولا تُنشر تلقائيًا.

## التشغيل

يلزم Node.js 22 أو أحدث وnpm. من جذر المستودع:

```bash
npm ci --prefix website
npm run build --prefix website
cd website
node scripts/audit-server.mjs
```

العرض المحلي: `http://127.0.0.1:8000`. مخرجات `website/dist` مولّدة وغير متتبعة في Git.

## الصور والتحميل

تُولّد صور WebP متجاوبة في أثناء البناء؛ صورة البداية فورية وبقية الصور مؤجلة. تبقى صورة لافتة صفحة «عن الدكتورة» كاملة دون قص. توجد إعادة محاولة عند تعذر تحميل الصور، والمحتوى قابل للقراءة دون JavaScript.

الخطوط والأيقونات والصور والبرامج محلية. بصمات `/static/<hash>/` تسمح بتخزين الأصول سنة؛ صفحات HTML والروابط الثابتة تعاد مراجعتها عند الطلب. لا يوجد غطاء تحميل يحجب المحتوى. الحركة تحترم تقليل الحركة وتستخدم صورة الشعار الأصلية مرة واحدة.

## البحث ومشاركة الروابط

عناوين ووصف وروابط canonical مستقلة للصفحات، وOpen Graph وTwitter، وصورة مشاركة عامة، وصور خاصة لصفحتي التعريف والتواصل والمقالات. تُبنى `robots.txt` و`sitemap.xml` تلقائيًا؛ صفحة 404 لا تُفهرس ولا تطلب رابطًا أساسيًا.

البيانات المنظمة تصف العيادة والطبيبة والخدمات والمقالات والأسئلة ومسارات التصفح. لا تضاف تقييمات أو إحداثيات أو مؤهلات غير موثقة. رابط الخرائط بحث بالعنوان؛ استقبال الولادة 24 ساعة مستقل عن دوام الخدمات الأخرى.

## التحقق

`npm run build` ينفذ فحوص الصفحات والروابط والمحتوى والأرشفة. تجري GitHub Actions فحص Chromium وWebKit عند طلب الدمج وإنتاج `main`:

- الصور والخطوط المحلية وبصمات الملفات وsrcset وpreload.
- عرض الصفحات من 320 إلى 1440 بكسل، والوصولية وعدم السحب الأفقي.
- القائمة ولوحة المفاتيح والعودة للأعلى وإعادة محاولة الصور.
- تقليل الحركة وتعطل JavaScript والتنسيق والتخزين.
- عينات أداء على اتصال هاتف محاكى؛ ليست قياسات مستخدمين حقيقيين.

تقارير الفحص ولقطاته مخرجات CI مؤقتة. لا تُنسخ سجلات الإصدارات والخطط القديمة إلى README أو توثيق التنفيذ.
