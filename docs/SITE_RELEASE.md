## ما يقدمه الموقع الجديد

- 18 صفحة ثابتة: الرئيسية، عن الدكتورة، الخدمات وتفاصيلها الست، الفحوص والمختبر، 4 مقالات توعوية وفهرسها، FAQ، التواصل، الخصوصية.
- الواجهة عربية RTL Mobile-first، بألوان الشعار الرقمية `#0C495C` و`#45A18E`، وشعار أصلي محفوظ.
- مسارات سريعة لمتابعة الحمل وأمراض النساء وتأخر الإنجاب، مع CTA اتصال وواتساب؛ خدمات التفاصيل تولّد رسالة استفسار باسم الخدمة دون بيانات مريض.
- تعريف بالمؤهلات ورؤية ورسالة، إرشادات الزيارة الأولى، شرح المختبر والفحوصات دون ذكر أجهزة أو إجراءات لم يتم تأكيدها.
- تمييز واضح بين دوام العيادة واستقبال **حالات الولادة** على مدار 24 ساعة فقط.
- بحث Google Maps بالعنوان المكتوب فقط، **ليس دبوس موقع مؤكداً**، إلى أن تتوفر مشاركة الموقع الرسمية.
- صور WebP تحريرية مصرح في وصفها بأنها توضيحية وليست صور المقر أو الطبيبة.
- بيانات `MedicalClinic` و`FAQPage` و`Article` و`BreadcrumbList` و`openingHoursSpecification` استناداً إلى الحقائق المعتمدة.
- صفحة خصوصية للتعامل مع روابط واتساب والخرائط والخطوط الخارجية، دون نموذج جمع بيانات صحية.

## نتائج المراجعة

- **Vercel:** بنية static جاهزة عبر `npm run build`.
- **فحوص ثابتة:** 18 مساراً، 38 مخرجاً، الروابط المحلية، RTL، الصور، العلامة، عنوان `h1` واحد، بيانات Open Graph والـ404.
- **Playwright + Chromium + Axe:** 52 حالة، 50 لقطة شاشة، **0 أخطاء و0 تحذيرات** في فحص commit `eb830533` على GitHub Actions: https://github.com/7eaur/dr-fayza/actions/runs/43293488322
- المقاسات: 320، 360، 390، 768، 1280، 1440 CSS px، وأغلب الصفحات على الهاتف والديسكتوب.
- **ملاحظة بيئة المعاينة:** Vercel Preview كان يفتح شاشة تسجيل دخول بدلاً من الموقع في بعض الاختبارات. أُصلح مسار الاختبار بحيث يبني الكود نفسه ويقدمه محلياً في GitHub Actions؛ لا يُسجل اختبار Vercel Preview المحجوب كخطأ HTML.
- قياسات LCP وINP وCLS على زيارات حقيقية وأجهزة حقيقية **غير متوفرة**، ولا ندعي تحققها.

## بيانات معلقة تتطلب العيادة

1. رابط موقع Google Maps الرسمي، ورابط فيسبوك بعد التثبت منهما.
2. صور مقر العيادة أو المختبر بإذن واضح؛ لا نعرض صوراً توليدية وكأنها حقيقية.
3. توثيق المسميات الرسمية للشهادات، توفر 4D والليزر وPRP، ونطاق العمليات ومكان إجرائها.
4. معلومات الاستقبال الإضافية للحالات المستعجلة؛ لا نعمم إعلان 24 ساعة على الطوارئ والخدمات الأخرى.
5. قياس أداء الهاتف والشبكات البطيئة والاختبار الإنساني بقارئ شاشة عند التوفر.
