# حملة افتتاح عيادة الدكتورة فايزة

هذا المجلد مخصص لحملة الافتتاح والإعلانات والعروض والنصوص والتصاميم المتعلقة بها.

## العناصر المطلوب إعدادها
- مواد إعلان الافتتاح.
- منشورات تفاصيل العروض والخصومات ومدة سريانها.
- منشورات تعريفية بالعيادة وخدماتها.
- قصص ومنشورات قابلة للنشر على شبكات التواصل.
- أصول التصميم والنصوص الأصلية والنسخ المعتمدة.

## حالة المعلومات
المحتوى والتصاميم تُجهز بعد تثبيت بيانات الافتتاح والعروض وأرقام التواصل والعنوان وأوقات العمل. لا تُفترض أسعار أو نسب خصومات.
